# Notion Daily Scrum Skill

Notion 페이지 또는 데이터베이스에 daily scrum 노트를 작성하고 관리하는 스킬입니다.
오전/오후 시간대에 맞춰 구성된 템플릿으로 스크럼 내용을 작성하고 Notion에 동기화합니다.

---

## 1. 사용 타이밍 (Triggers)

사용자가 다음과 같은 요청을 할 때 이 스킬을 활용합니다:
- "노션에 데일리 스크럼 써줘"
- "오전 스크럼 작성해줘" / "어제 한 일이랑 오늘 할 일 정리해줘"
- "오후 스크럼 작성해줘" / "오늘 한 일 정리해서 노션에 올리고 싶어"
- "Notion 데일리 스크럼 템플릿 작성"

---

## 2. 데일리 스크럼 템플릿 양식

### ☀️ 오전 스크럼 (Morning Scrum)
- **작성 시점**: 매일 오전 작업 시작 시
- **구성 항목**:
  1. **어제 한 일 (Yesterday's Completed)**: 전날 완료한 작업 목록
  2. **오늘 할 일 (Today's Plan)**: 오늘 진행할 주요 목표 및 우선순위 항목
  3. **장애 요인 (Blockers / Risks)**: 작업 진행을 방해하는 이슈나 도움이 필요한 항목

#### 📝 오전 포맷 예시:
```markdown
## ☀️ [YYYY-MM-DD] 오전 데일리 스크럼

### ⏪ 어제 한 일
- [x] 작업 1 상세 내용
- [x] 작업 2 상세 내용

### 🎯 오늘 할 일
- [ ] [우선순위 High] 오늘 진행할 주요 작업 1
- [ ] 오늘 진행할 작업 2

### 🚧 장애 및 도움이 필요한 사항 (Blockers)
- 없음 (또는 관련 이슈/질문 작성)
```

---

### 🌙 오후 스크럼 (Evening Wrap-up)
- **작성 시점**: 매일 오후 작업 종료 시
- **구성 항목**:
  1. **오늘 한 일 (Today's Achievements)**: 오늘 실제로 완료하거나 진행한 작업
  2. **미완료 항목 및 사유 (Incomplete Items)**: 오늘 완수하지 못한 항목과 변경된 계획
  3. **오늘의 회고 / 메모 (Notes & Reflection)**: 배운 점, 공유할 내용 등

#### 📝 오후 포맷 예시:
```markdown
## 🌙 [YYYY-MM-DD] 오후 데일리 스크럼 / 일일 회고

### ✅ 오늘 한 일
- [x] 완료한 작업 1 (관련 PR/링크)
- [x] 완료한 작업 2

### ⏳ 미완료 항목 및 이월 작업
- [ ] 미완료 항목 (사유: ~~)

### 💡 오늘의 메모 및 배운 점
- 오늘 해결한 버그 원인 정리 또는 배운 점 메모
```

---

## 3. 실행 가이드 (Execution Workflow)

1. **시간대 확인 및 정보 수집**:
   - 현재 시간대가 오전인지 오후인지 확인하거나 사용자에게 어떤 세션 스크럼인지 파악합니다.
   - 최근 작업 내역(커밋 로그, 이슈 목록, 대화 맥락)을 기반으로 스크럼 내용을 자동 구성하거나 사용자에게 입력을 요청합니다.

2. **Notion 작성/업데이트**:
   - Notion MCP 또는 `NOTION_API_KEY` 연동 도구를 이용해 대상 노션 페이지/데이터베이스를 검색 및 생성합니다.
   - 해당 날짜의 페이지가 이미 존재하는 경우:
     - 오전이면 `☀️ 오전 데일리 스크럼` 섹션을 추가/업데이트합니다.
     - 오후이면 `🌙 오후 데일리 스크럼` 섹션을 덧붙여 갱신합니다.

3. **결과 확인**:
   - 작성된 Markdown / Notion 블록 구조를 사용자에게 미리 보여주고, 링크 또는 생성 결과를 공유합니다.
