# 29CM Design System Guide for PRDView

## 1. Visual Theme & Atmosphere
- Canvas: `#ffffff`
- Primary / Foreground: `#000000`
- Muted: `#5d5d5d`
- Secondary Ink: `#303033`
- Tertiary Ink: `#474747`
- Border: `#dddddd`
- Sale Accent / Highlighting: `#ff4800`
- Typography: Pretendard Variable (Sans-serif)
- Corner Radii: Flat 0px, 2px, 4px (Ghost buttons), 10px chips, 9999px pills.
- Shadow: Flat `none` (use `#dddddd` clean hairlines).

## 2. Typography Rules
- Main Navigation / App Bar: Bold 20px - 24px
- Section Titles / Screen Names: 23px / 600 weight
- Body Text: 15px - 16px / 400 weight (line-height 1.6)
- Wireframe Node Component Name: 13px - 14px / 700 weight
- Props / Event Label: 11px - 12px / 500 weight `#474747`
- Highlighting / Diff Accent: `#ff4800` with subtle tint background `#fff5f2`
